# LEVIR-MCI Dataset

RS-Agent uses the LEVIR-MCI release referenced by Change-Agent. Dataset files are kept outside Git.


The archive was downloaded from `lcybuaa/LEVIR-MCI` on Hugging Face and validated before extraction.

The release contains bi-temporal images, change labels, RGB labels, and `LevirCCcaptions.json`. The annotation JSON stores five human captions per pair.

## Experimental Use

The five reference captions are evaluation annotations. The paper-aligned RS-CC input is instead one caption generated by Change-Agent for each image pair. A later preprocessing step must therefore generate or import a one-record-per-pair JSONL file before a formal RS-CC run.

RS-VQA will consume only the original A/B images. Optional masks can be attached as evidence but are not mandatory inputs for caption enrichment.
