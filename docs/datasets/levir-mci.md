## Experimental Use

The five LEVIR-MCI reference captions remain evaluation annotations. The paper-aligned RS-CC input is one caption generated by Change-Agent for each image pair. RS-VQA will consume only the original A/B images. Optional masks can be attached as evidence but are not mandatory inputs for caption enrichment.
